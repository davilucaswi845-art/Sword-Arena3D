SWORD ARENA 3D — PROJETO ANDROID

Este projeto prepara o jogo HTML como aplicativo Android com:
- Nome: Sword Arena 3D
- Ícone próprio de espada e escudo
- Tela cheia e orientação horizontal
- WebView com armazenamento local para as contas demonstrativas

COMO GERAR O APP:
1. Instale o Android Studio em um computador.
2. Extraia esta pasta.
3. No Android Studio, escolha Open e selecione a pasta Sword_Arena_3D_Android.
4. Aguarde a sincronização do Gradle.
5. Para testar: Run > Run 'app' com um celular Android conectado ou emulador.
6. Para gerar arquivo da Play Store: Build > Generate Signed Bundle / APK > Android App Bundle.
7. Crie/seleciona uma chave de assinatura e gere o arquivo .aab.

IMPORTANTE:
- O jogo carrega Three.js da internet (jsDelivr), então precisa de conexão.
- As contas criadas no jogo ficam apenas naquele aparelho; não são contas online.
- O projeto ainda precisa ser compilado e testado no Android Studio antes de publicar.
- A publicação na Google Play exige uma conta de desenvolvedor elegível e cumprir os testes/requisitos atuais da loja.
